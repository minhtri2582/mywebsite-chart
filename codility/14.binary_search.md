# Binary Search Algorithm - Ôn luyện Brown Belt

Nhóm bài "Binary Search Algorithm" tập trung vào:
1. **Binary Search cơ bản** - Tìm kiếm trong mảng đã sắp xếp
2. **Binary Search variants** - First/last occurrence, lower/upper bound
3. **Binary Search on Answer** - Tìm giá trị tối ưu bằng binary search

**Kiến thức cần nhớ:**
- Binary search: O(log n) time, O(1) space
- Điều kiện: Mảng phải được sắp xếp (hoặc có tính chất đơn điệu)
- Pattern: Tìm giá trị nhỏ nhất/lớn nhất thỏa mãn điều kiện

## 📚 Giới thiệu: Binary Search (Tìm kiếm nhị phân)

### Ý tưởng cơ bản

Binary search tìm kiếm phần tử trong mảng **đã sắp xếp** bằng cách:
1. So sánh phần tử ở giữa với target
2. Loại bỏ một nửa mảng không thể chứa target
3. Lặp lại trên nửa còn lại

**Ví dụ:** Tìm số 7 trong [1, 3, 5, 7, 9, 11, 13]

| Bước | Left | Right | Mid | A[Mid] | So sánh | Action |
|------|------|-------|-----|--------|---------|--------|
| 1    | 0    | 6     | 3   | 7      | == 7    | ✅ Tìm thấy! |

### Binary Search Standard

Tìm vị trí của target trong mảng đã sắp xếp (hoặc -1 nếu không tìm thấy).

```python
def binary_search(A, target):
    left, right = 0, len(A) - 1
    while left <= right:
        mid = (left + right) // 2
        if A[mid] == target:
            return mid
        elif A[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1  # Không tìm thấy
```

**Độ phức tạp:** O(log n) time, O(1) space

### Binary Search - First Occurrence

Tìm vị trí **đầu tiên** của target (lower bound).

```python
def first_occurrence(A, target):
    left, right = 0, len(A) - 1
    result = -1
    while left <= right:
        mid = (left + right) // 2
        if A[mid] == target:
            result = mid
            right = mid - 1  # Tiếp tục tìm bên trái
        elif A[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return result
```

### Binary Search - Last Occurrence

Tìm vị trí **cuối cùng** của target (upper bound).

```python
def last_occurrence(A, target):
    left, right = 0, len(A) - 1
    result = -1
    while left <= right:
        mid = (left + right) // 2
        if A[mid] == target:
            result = mid
            left = mid + 1  # Tiếp tục tìm bên phải
        elif A[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return result
```

### Binary Search on Answer

**Pattern quan trọng:** Khi bài toán yêu cầu tìm giá trị **nhỏ nhất/lớn nhất** thỏa mãn điều kiện:

1. **Xác định phạm vi:** [left, right]
2. **Hàm kiểm tra:** `canAchieve(value)` → True/False
3. **Binary search:** 
   - Nếu `canAchieve(mid)` → có thể giảm giá trị (tìm min)
   - Ngược lại → phải tăng giá trị

```python
def binary_search_on_answer(left, right):
    result = right
    while left <= right:
        mid = (left + right) // 2
        if canAchieve(mid):
            result = mid
            right = mid - 1  # Tìm giá trị nhỏ hơn
        else:
            left = mid + 1   # Phải tăng giá trị
    return result
```

## 1) Problem: MinMaxDivision

### Description
Chia mảng `A` có N phần tử thành **K đoạn liên tiếp** sao cho **tổng lớn nhất của các đoạn là nhỏ nhất có thể**.

**Ví dụ:**
- A = [2, 1, 5, 1, 2, 2, 2], K = 3
- Có thể chia: [2,1,5] [1,2,2] [2] → tổng = [8, 5, 2], max = 8
- Hoặc: [2,1] [5,1,2] [2,2] → tổng = [3, 8, 4], max = 8
- Tìm cách chia sao cho max nhỏ nhất

### Tư duy giải

**Key Insight - Binary Search on Answer:**
- Không thể brute force (quá nhiều cách chia)
- Dùng binary search trên **giá trị tổng lớn nhất**

**Cách tiếp cận:**
1. **Xác định phạm vi:**
   - `left = max(A)` (mỗi đoạn phải chứa ít nhất 1 phần tử)
   - `right = sum(A)` (tổng toàn bộ mảng)
2. **Hàm kiểm tra:** `canDivide(maxSum)` 
   - Kiểm tra xem có thể chia thành ≤ K đoạn với mỗi đoạn có tổng ≤ maxSum không
3. **Binary search:** Tìm giá trị nhỏ nhất thỏa mãn

**Thuật toán kiểm tra `canDivide(maxSum)`:**
```
segments = 1
currentSum = 0
for each element in A:
    if currentSum + element > maxSum:
        segments++
        currentSum = element
    else:
        currentSum += element
return segments <= K
```

### Complexity
- Time: **O(N × log(sum(A)))** - N lần kiểm tra, mỗi lần O(N)
- Space: **O(1)**

### Ví dụ chi tiết từng bước

**A = [2, 1, 5, 1, 2, 2, 2], K = 3**

**Bước 1: Xác định phạm vi**
- max(A) = 5 → left = 5
- sum(A) = 15 → right = 15

**Bước 2: Binary search**

| Iteration | left | right | mid | canDivide(mid)? | Segments | Action |
|-----------|------|-------|-----|-----------------|----------|--------|
| 1         | 5    | 15    | 10  | ✅ (2 segments) | 2 ≤ 3    | Tìm nhỏ hơn: right = 9 |
| 2         | 5    | 9     | 7   | ✅ (3 segments) | 3 ≤ 3    | Tìm nhỏ hơn: right = 6 |
| 3         | 5    | 6     | 5   | ❌ (4 segments) | 4 > 3    | Phải tăng: left = 6 |
| 4         | 6    | 6     | 6   | ✅ (3 segments) | 3 ≤ 3    | Tìm nhỏ hơn: right = 5 |
| 5         | 6    | 5     | -   | -               | -        | left > right, dừng |

**Kết quả:** 6

**Chi tiết kiểm tra canDivide(7):**
- Đoạn 1: 2+1+5 = 8 > 7 → tách: [2,1] [5]
- Đoạn 2: 5+1 = 6 ≤ 7 → [2,1] [5,1]
- Đoạn 3: 5+1+2 = 8 > 7 → tách: [2,1] [5,1] [2]
- Đoạn 4: 2+2 = 4 ≤ 7 → [2,1] [5,1] [2,2]
- Đoạn 5: 2+2+2 = 6 ≤ 7 → [2,1] [5,1] [2,2,2]
- Tổng: 3 đoạn [2,1] [5,1,2] [2,2] → ✅ 3 ≤ 3

**Chi tiết kiểm tra canDivide(6):**
- Đoạn 1: 2+1+5 = 8 > 6 → tách: [2,1] [5]
- Đoạn 2: 5+1 = 6 ≤ 6 → [2,1] [5,1]
- Đoạn 3: 5+1+2 = 8 > 6 → tách: [2,1] [5,1] [2]
- Đoạn 4: 2+2 = 4 ≤ 6 → [2,1] [5,1] [2,2]
- Đoạn 5: 2+2+2 = 6 ≤ 6 → [2,1] [5,1] [2,2,2]
- Tổng: 3 đoạn [2,1] [5,1,2] [2,2,2] → ✅ 3 ≤ 3

**Chi tiết kiểm tra canDivide(5):**
- Đoạn 1: 2+1+5 = 8 > 5 → tách: [2,1] [5]
- Đoạn 2: 5 > 5 → tách: [2,1] [5] (riêng)
- Đoạn 3: 1+2 = 3 ≤ 5 → [2,1] [5] [1,2]
- Đoạn 4: 1+2+2 = 5 ≤ 5 → [2,1] [5] [1,2,2]
- Đoạn 5: 2+2 = 4 ≤ 5 → [2,1] [5] [1,2,2] [2]
- Tổng: 4 đoạn > 3 → ❌

### Edge Cases

1. **K = 1:** return sum(A)
2. **K = N:** return max(A) (mỗi phần tử một đoạn)
3. **K > N:** Không hợp lệ (theo đề bài K ≤ N)

### ✔ PHP Solution

```php
function canDivide($A, $K, $maxSum) {
    $segments = 1;
    $currentSum = 0;
    
    foreach ($A as $val) {
        if ($currentSum + $val > $maxSum) {
            $segments++;
            $currentSum = $val;
            if ($segments > $K) {
                return false;
            }
        } else {
            $currentSum += $val;
        }
    }
    
    return $segments <= $K;
}

function solution($K, $M, $A) {
    $n = count($A);
    $left = max($A);
    $right = array_sum($A);
    $result = $right;
    
    while ($left <= $right) {
        $mid = intval(($left + $right) / 2);
        if (canDivide($A, $K, $mid)) {
            $result = $mid;
            $right = $mid - 1;
        } else {
            $left = $mid + 1;
        }
    }
    
    return $result;
}
```

### ✔ Python Solution

```python
def can_divide(A, K, max_sum):
    segments = 1
    current_sum = 0
    
    for val in A:
        if current_sum + val > max_sum:
            segments += 1
            current_sum = val
            if segments > K:
                return False
        else:
            current_sum += val
    
    return segments <= K

def solution(K, M, A):
    left = max(A)
    right = sum(A)
    result = right
    
    while left <= right:
        mid = (left + right) // 2
        if can_divide(A, K, mid):
            result = mid
            right = mid - 1
        else:
            left = mid + 1
    
    return result
```

### Tips & Tricks
- ✅ **Pattern:** Binary search on answer khi tìm min/max thỏa mãn điều kiện
- ✅ **Left bound:** max(A) - mỗi đoạn phải chứa ít nhất 1 phần tử
- ✅ **Hàm kiểm tra:** Greedy - cố gắng gộp nhiều phần tử nhất có thể
- ⚠️ Chú ý: segments bắt đầu từ 1 (đoạn đầu tiên)
- 💡 **Insight:** Nếu có thể chia với maxSum = X, thì có thể chia với maxSum > X

## 2) Problem: NailingPlanks

### Description
Cho N tấm ván, mỗi tấm ván i có điểm đầu `A[i]` và điểm cuối `B[i]` (A[i] ≤ B[i]). Có M cây đinh ở các vị trí `C[j]`. Một tấm ván được "đóng" nếu có ít nhất 1 cây đinh trong khoảng [A[i], B[i]].

**Yêu cầu:** Tìm số lượng đinh **tối thiểu** (từ đầu mảng C) cần dùng để đóng **tất cả** các tấm ván. Nếu không thể, return -1.

### Tư duy giải

**Key Insight - Binary Search on Answer:**
- Không thể thử tất cả cách sắp xếp đinh
- Dùng binary search trên **số lượng đinh** (1 đến M)

**Cách tiếp cận:**
1. **Sắp xếp đinh** theo vị trí để dễ tìm kiếm
2. **Xác định phạm vi:** left = 1, right = M
3. **Hàm kiểm tra:** `canNailAll(nails)`
   - Kiểm tra xem với n đinh đầu tiên, có thể đóng tất cả tấm ván không
   - Với mỗi tấm ván, tìm đinh gần nhất trong khoảng [A[i], B[i]]
4. **Binary search:** Tìm số lượng đinh nhỏ nhất

**Thuật toán kiểm tra:**
```
Đinh đã sắp xếp: nails[0..n-1]
for each plank (A[i], B[i]):
    Tìm đinh đầu tiên >= A[i] (lower bound)
    if đinh không tồn tại hoặc đinh > B[i]:
        return false
return true
```

### Complexity
- Time: **O((N + M) × log M)**
  - Sắp xếp đinh: O(M log M)
  - Binary search: O(log M)
  - Mỗi lần kiểm tra: O(N × log M) (binary search cho mỗi tấm ván)
- Space: **O(M)** - mảng đinh đã sắp xếp

### Ví dụ chi tiết từng bước

**A = [1, 4, 5, 8], B = [4, 5, 9, 10], C = [4, 6, 7, 10, 2]**

**Tấm ván:**
- Plank 0: [1, 4]
- Plank 1: [4, 5]
- Plank 2: [5, 9]
- Plank 3: [8, 10]

**Bước 1: Sắp xếp đinh C = [2, 4, 6, 7, 10]**

**Bước 2: Binary search trên số lượng đinh**

| Iteration | left | right | mid | canNailAll(mid)? | Action |
|-----------|------|-------|-----|------------------|--------|
| 1         | 1    | 5     | 3   | ❌ (thiếu plank 3) | Tăng: left = 4 |
| 2         | 4    | 5     | 4   | ✅ (đủ tất cả)    | Tìm nhỏ hơn: right = 3 |
| 3         | 4    | 3     | -   | -                 | left > right, dừng |

**Kết quả:** 4

**Chi tiết kiểm tra canNailAll(3):**
- Đinh: [2, 4, 6]
- Plank 0 [1,4]: Tìm đinh >= 1 → 2, kiểm tra 2 ≤ 4? ✅
- Plank 1 [4,5]: Tìm đinh >= 4 → 4, kiểm tra 4 ≤ 5? ✅
- Plank 2 [5,9]: Tìm đinh >= 5 → 6, kiểm tra 6 ≤ 9? ✅
- Plank 3 [8,10]: Tìm đinh >= 8 → không có ❌
- → Thiếu plank 3

**Chi tiết kiểm tra canNailAll(4):**
- Đinh: [2, 4, 6, 7]
- Plank 0 [1,4]: Tìm đinh >= 1 → 2, kiểm tra 2 ≤ 4? ✅
- Plank 1 [4,5]: Tìm đinh >= 4 → 4, kiểm tra 4 ≤ 5? ✅
- Plank 2 [5,9]: Tìm đinh >= 5 → 6, kiểm tra 6 ≤ 9? ✅
- Plank 3 [8,10]: Tìm đinh >= 8 → 7? Không, 7 < 8 → không có ❌
- Wait, kiểm tra lại: đinh 7 < 8, nhưng có đinh 10 (nếu dùng 5 đinh)

**Điều chỉnh:** Với mid=4, ta chỉ dùng 4 đinh đầu [2,4,6,7]. Cần kiểm tra lại:

**canNailAll(4) với đinh [2,4,6,7]:**
- Plank 3 [8,10]: Không có đinh nào trong [8,10] ❌

**canNailAll(5) với đinh [2,4,6,7,10]:**
- Plank 3 [8,10]: Đinh 10, kiểm tra 10 ≤ 10? ✅
- → Đủ tất cả ✅

**Kết quả đúng:** 5 đinh

### Edge Cases

1. **Tất cả tấm ván trùng nhau:** Cần 1 đinh nếu đinh nằm trong khoảng
2. **Không có đinh nào đóng được:** return -1
3. **Mỗi tấm ván cần đinh riêng:** return N (nếu N ≤ M)

### ✔ PHP Solution

```php
function lower_bound($arr, $target) {
    $left = 0;
    $right = count($arr) - 1;
    $result = -1;
    
    while ($left <= $right) {
        $mid = intval(($left + $right) / 2);
        if ($arr[$mid] >= $target) {
            $result = $mid;
            $right = $mid - 1;
        } else {
            $left = $mid + 1;
        }
    }
    
    return $result;
}

function canNailAll($A, $B, $nails, $numNails) {
    $n = count($A);
    $sortedNails = array_slice($nails, 0, $numNails);
    sort($sortedNails);
    
    for ($i = 0; $i < $n; $i++) {
        $pos = lower_bound($sortedNails, $A[$i]);
        if ($pos == -1 || $sortedNails[$pos] > $B[$i]) {
            return false;
        }
    }
    
    return true;
}

function solution($A, $B, $C) {
    $m = count($C);
    $left = 1;
    $right = $m;
    $result = -1;
    
    while ($left <= $right) {
        $mid = intval(($left + $right) / 2);
        if (canNailAll($A, $B, $C, $mid)) {
            $result = $mid;
            $right = $mid - 1;
        } else {
            $left = $mid + 1;
        }
    }
    
    return $result;
}
```

### ✔ Python Solution

```python
import bisect

def can_nail_all(A, B, nails, num_nails):
    sorted_nails = sorted(nails[:num_nails])
    n = len(A)
    
    for i in range(n):
        pos = bisect.bisect_left(sorted_nails, A[i])
        if pos == len(sorted_nails) or sorted_nails[pos] > B[i]:
            return False
    
    return True

def solution(A, B, C):
    m = len(C)
    left, right = 1, m
    result = -1
    
    while left <= right:
        mid = (left + right) // 2
        if can_nail_all(A, B, C, mid):
            result = mid
            right = mid - 1
        else:
            left = mid + 1
    
    return result
```

### Tips & Tricks
- ✅ **Sắp xếp đinh:** Cần sắp xếp để dùng binary search
- ✅ **Lower bound:** Dùng `bisect.bisect_left()` trong Python hoặc tự implement
- ✅ **Tối ưu:** Chỉ sắp xếp n đinh đầu tiên trong hàm kiểm tra (không sắp xếp toàn bộ)
- ⚠️ Chú ý: Kiểm tra đinh có tồn tại và nằm trong khoảng [A[i], B[i]]
- 💡 **Insight:** Nếu có thể đóng với n đinh, thì có thể đóng với > n đinh

## Summary - Tóm tắt

| Problem        | Output                              | Core Idea                                    | Time                | Space |
| -------------- | ----------------------------------- | -------------------------------------------- | ------------------- | ----- |
| Binary Search  | Tìm target trong mảng đã sắp xếp    | Chia đôi phạm vi tìm kiếm                    | O(log n)            | O(1)  |
| MinMaxDivision | Tổng lớn nhất nhỏ nhất               | Binary search on answer + Greedy check       | O(N × log(sum))     | O(1)  |
| NailingPlanks  | Số đinh tối thiểu                   | Binary search on answer + Lower bound        | O((N+M) × log M)    | O(M)  |

### Kiến thức cốt lõi cho Brown Belt

1. **Binary Search cơ bản:**
   - Điều kiện: Mảng đã sắp xếp (hoặc có tính đơn điệu)
   - Pattern: `while left <= right`, `mid = (left + right) // 2`
   - Chú ý: Tránh infinite loop (left = mid + 1, right = mid - 1)

2. **Binary Search Variants:**
   - First occurrence: Tiếp tục tìm bên trái khi tìm thấy
   - Last occurrence: Tiếp tục tìm bên phải khi tìm thấy
   - Lower bound: Phần tử đầu tiên >= target
   - Upper bound: Phần tử đầu tiên > target

3. **Binary Search on Answer:**
   - Khi tìm min/max thỏa mãn điều kiện
   - Xác định phạm vi [left, right] hợp lý
   - Viết hàm kiểm tra `canAchieve(value)` chính xác
   - Pattern: Nếu `canAchieve(mid)` → tìm nhỏ hơn, ngược lại tìm lớn hơn

4. **MinMaxDivision:**
   - Binary search trên giá trị tổng lớn nhất
   - Hàm kiểm tra: Greedy chia đoạn
   - Left bound = max(A), right bound = sum(A)

5. **NailingPlanks:**
   - Binary search trên số lượng đinh
   - Sắp xếp đinh để dùng lower bound
   - Kiểm tra mỗi tấm ván có đinh trong khoảng

6. **Tối ưu:**
   - Dùng built-in functions: `bisect` trong Python
   - Tránh sắp xếp lại nhiều lần (cache kết quả)
   - Chú ý boundary conditions (left > right)
