# Codility Lesson 6: Sorting — Song ngữ Anh – Việt

## 1. Distinct — Phần tử khác nhau

### ✨ Problem / Bài toán

**EN:** Given an array `A`, count the number of distinct values.

**VI:** Cho mảng `A`, đếm số lượng giá trị **khác nhau** trong mảng.

---

### 🔍 Key idea / Ý chính

* Dùng **set** trong Python hoặc **array_unique()** trong PHP để loại trùng.
* Độ phức tạp phụ thuộc vào việc sắp xếp hoặc hash.

---

### 📊 Example / Ví dụ

| A             | Result | Giải thích                  |
| ------------- | ------ | --------------------------- |
| [2,1,1,2,3,1] | 3      | Các giá trị duy nhất: 1,2,3 |

---

### 💻 Python Code

```python
def distinct(A):
    return len(set(A))

print(distinct([2,1,1,2,3,1]))  # 3
```

### 💻 PHP Code

```php
<?php
function distinct(array $A): int {
    return count(array_unique($A));
}

echo distinct([2,1,1,2,3,1]); // 3
```

**Complexity:** O(N log N) time (sort-based) or O(N) average with hashing.

## 2. MaxProductOfThree — Tích lớn nhất của ba số

### ✨ Problem / Bài toán

**EN:** Given a non-empty array `A` of integers, find the maximal product of any triplet.

**VI:** Cho mảng `A` không rỗng gồm các số nguyên, tìm tích lớn nhất của **3 phần tử bất kỳ**.

---

### 🔍 Key idea / Ý chính

* Sau khi **sắp xếp mảng**, tích lớn nhất có thể đến từ:

  * `A[-1] * A[-2] * A[-3]` (3 số lớn nhất), hoặc
  * `A[0] * A[1] * A[-1]` (2 số âm nhỏ nhất và số dương lớn nhất).
* Lấy **max** của 2 giá trị trên.

---

### 📊 Example / Ví dụ

| A                  | Result | Giải thích        |
| ------------------ | ------ | ----------------- |
| [-3,1,2,-2,5,6]    | 60     | 5×6×2 = 60        |
| [-5, -6, -4, 2, 3] | 120    | (-6)×(-5)×4 = 120 |

---

### 💻 Python Code

```python
def max_product_of_three(A):
    A.sort()
    return max(A[-1]*A[-2]*A[-3], A[0]*A[1]*A[-1])

print(max_product_of_three([-3,1,2,-2,5,6]))  # 60
```

### 💻 PHP Code

```php
<?php
function max_product_of_three(array $A): int {
    sort($A);
    $n = count($A);
    $p1 = $A[$n-1] * $A[$n-2] * $A[$n-3];
    $p2 = $A[0] * $A[1] * $A[$n-1];
    return max($p1, $p2);
}

echo max_product_of_three([-3,1,2,-2,5,6]); // 60
```

**Complexity:** O(N log N) time, O(1) space.

## 3. Triangle — Tam giác

### ✨ Problem / Bài toán

**EN:** Determine whether a triangle can be built from any three numbers in array `A`.

**VI:** Kiểm tra xem có thể tạo được **tam giác** từ bất kỳ 3 số trong mảng `A` hay không.

---

### 🔍 Key idea / Ý chính

* Điều kiện tam giác: với 3 cạnh `a ≤ b ≤ c`, phải có `a + b > c`.
* Sau khi **sắp xếp mảng**, chỉ cần kiểm tra từng bộ 3 liên tiếp.

---

### 📊 Example / Ví dụ

| A               | Result | Giải thích                        |
| --------------- | ------ | --------------------------------- |
| [10,2,5,1,8,20] | 1      | 5 + 8 > 10 → có thể tạo tam giác  |
| [10,50,5,1]     | 0      | Không tồn tại bộ 3 thỏa điều kiện |

---

### 💻 Python Code

```python
def triangle(A):
    A.sort()
    for i in range(len(A)-2):
        if A[i] + A[i+1] > A[i+2]:
            return 1
    return 0

print(triangle([10,2,5,1,8,20]))  # 1
```

### 💻 PHP Code

```php
<?php
function triangle(array $A): int {
    sort($A);
    for ($i=0; $i<count($A)-2; $i++) {
        if ($A[$i] + $A[$i+1] > $A[$i+2]) return 1;
    }
    return 0;
}

echo triangle([10,2,5,1,8,20]); // 1
```

**Complexity:** O(N log N) time, O(1) space.
