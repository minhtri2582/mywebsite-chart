## 1. CyclicRotation — Xoay mảng vòng

### ✨ Problem / Bài toán

**EN:** Rotate array `A` to the right by `K` steps (cyclic).
**VI:** Xoay mảng `A` sang phải `K` lần theo chu kỳ (phần tử cuối chạy về đầu).

---

### 🔍 Key idea / Ý chính

* If `A` is empty or `K % len(A) == 0` → array unchanged.
* Reduce rotations: `K = K % N`.
* Use slicing or `array_slice()` instead of manual loops.

---

### 📊 Examples / Ví dụ

| A               | K | Result          | Giải thích                      |
| --------------- | - | --------------- | ------------------------------- |
| [3, 8, 9, 7, 6] | 3 | [9, 7, 6, 3, 8] | 3 phần tử cuối được đưa lên đầu |
| [0, 0, 0]       | 1 | [0, 0, 0]       | Tất cả giống nhau               |
| [1, 2, 3, 4]    | 4 | [1, 2, 3, 4]    | K = N, không thay đổi           |
| []              | 5 | []              | Mảng rỗng                       |

---

### 💻 Python Code

```python
def cyclic_rotation(A, K):
    n = len(A)
    if n == 0:
        return A
    K %= n
    if K == 0:
        return A
    return A[-K:] + A[:-K]

# Test
print(cyclic_rotation([3,8,9,7,6], 3))  # [9,7,6,3,8]
```

---

### 💻 PHP Code

```php
<?php
function cyclic_rotation(array $A, int $K): array {
    $n = count($A);
    if ($n === 0) return $A;
    $K = $K % $n;
    if ($K === 0) return $A;

    $tail = array_slice($A, $n - $K);
    $head = array_slice($A, 0, $n - $K);
    return array_merge($tail, $head);
}

print_r(cyclic_rotation([3,8,9,7,6], 3)); // [9,7,6,3,8]
```

**Complexity:** O(N) time, O(N) space.

## 2. OddOccurrencesInArray — Phần tử xuất hiện lẻ

### ✨ Problem / Bài toán

**EN:** In an array where all elements appear an even number of times except one, find that unpaired element.
**VI:** Trong mảng mà mỗi phần tử xuất hiện số lần chẵn, chỉ một phần tử xuất hiện lẻ → tìm phần tử đó.

---

### 🔍 Key idea / Ý chính

**XOR Trick:**
`x ^ x = 0` và `x ^ 0 = x`. XOR là giao hoán và kết hợp được.
XOR toàn bộ phần tử → kết quả chính là giá trị không có cặp.

---

### 📊 Examples / Ví dụ

| A                     | Result | Giải thích             |
| --------------------- | ------ | ---------------------- |
| [9, 3, 9, 3, 9, 7, 9] | 7      | Chỉ 7 xuất hiện 1 lần  |
| [42]                  | 42     | Một phần tử duy nhất   |
| [2, 2, 2, 3, 3]       | 2      | Chỉ 2 xuất hiện 3 (lẻ) |

---

### 💻 Python Code (XOR)

```python
def odd_occurrence_xor(A):
    x = 0
    for v in A:
        x ^= v
    return x

print(odd_occurrence_xor([9,3,9,3,9,7,9]))  # 7
```

---

### 💻 PHP Code (XOR)

```php
<?php
function odd_occurrence_xor(array $A): int {
    $x = 0;
    foreach ($A as $v) {
        $x ^= $v;
    }
    return $x;
}

echo odd_occurrence_xor([9,3,9,3,9,7,9]); // 7
```

---

### 🔢 Alternate Method / Cách khác (Count map)

**Python:**

```python
from collections import Counter

def odd_occurrence_count(A):
    cnt = Counter(A)
    for k, v in cnt.items():
        if v % 2 == 1:
            return k
```

**PHP:**

```php
<?php
function odd_occurrence_count(array $A) {
    $cnt = [];
    foreach ($A as $v) {
        $cnt[$v] = ($cnt[$v] ?? 0) + 1;
    }
    foreach ($cnt as $k => $v) {
        if ($v % 2 === 1) return (int)$k;
    }
    return null;
}
```

**Complexity:** O(N) time, O(1) space with XOR.
