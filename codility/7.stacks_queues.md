# Codility – Stacks & Queues (Theory + Examples + Solutions in PHP & Python)

## 1. Basic Concepts

### 🧱 Stack
- LIFO – Last In, First Out
- Common operations:
  - `push(x)` – add element on top
  - `pop()` – remove top element
  - `top()` – view top element
- Use cases:
  - Validate brackets
  - Evaluate expressions
  - Undo/redo history
  - StoneWall block counting

### 🚋 Queue
- FIFO – First In, First Out
- Use cases:
  - BFS, scheduling
  - Task/job processing

Most Codility problems here focus on **Stack**.

## 2. Problem 1: Brackets

### Description
Given a string with only characters `()[]{}`, verify if brackets are properly nested.

### Examples
| Input | Output |
|--------|--------|
| `{[()]}` | 1 |
| `([)]` | 0 |
| `()[]{} ` | 1 |

### Approach
Use a Stack: push open brackets, pop and validate closing ones.

---

### PHP Solution
```php
function solution($S) {
    $stack = [];
    $pairs = [')' => '(', ']' => '[', '}' => '{'];

    foreach (str_split($S) as $ch) {
        if (in_array($ch, ['(', '[', '{'])) {
            array_push($stack, $ch);
        } else {
            if (empty($stack)) return 0;
            $top = array_pop($stack);
            if ($pairs[$ch] !== $top) return 0;
        }
    }
    return empty($stack) ? 1 : 0;
}
```

### Python Solution

```python
def solution(S):
    stack = []
    matching = {')': '(', ']': '[', '}': '{'}
    for ch in S:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack.pop() != matching[ch]:
                return 0
    return 1 if not stack else 0
```

## 3. Problem 2: Nesting

### Description
Validate a string containing only ( and ).

### Approach

Use counter instead of stack: increment on (, decrement on ).

### ✔ PHP Solution
```php
function solution($S) {
    $count = 0;
    foreach (str_split($S) as $ch) {
        $count += ($ch === '(') ? 1 : -1;
        if ($count < 0) return 0;
    }
    return $count === 0 ? 1 : 0;
}
```
### ✔ Python Solution
```python
def solution(S):
    count = 0
    for ch in S:
        count += 1 if ch == '(' else -1
        if count < 0:
            return 0
    return 1 if count == 0 else 0
```

## 4. Problem 3: Fish

### Description
Simulate fish swimming direction & size survival.
- A[i] = size
- B[i] = direction (0 upstream, 1 downstream)

### Approach

Use stack to store downstream fish and simulate fights.

### ✔ PHP Solution
```php
function solution($A, $B) {
    $stack = [];
    $aliveUpstream = 0;

    for ($i = 0; $i < count($A); $i++) {
        $size = $A[$i];
        $dir = $B[$i];

        if ($dir == 1) {
            array_push($stack, $size);
        } else {
            $alive = true;
            while (!empty($stack) && $alive) {
                $last = end($stack);
                if ($last > $size) {
                    $alive = false;
                } else {
                    array_pop($stack);
                }
            }
            if ($alive) $aliveUpstream++;
        }
    }
    return $aliveUpstream + count($stack);
}
```
### ✔ Python Solution
```python
def solution(A, B):
    stack = []
    aliveUpstream = 0
    for size, direction in zip(A, B):
        if direction == 1:
            stack.append(size)
        else:
            alive = True
            while stack and alive:
                if stack[-1] > size:
                    alive = False
                else:
                    stack.pop()
            if alive:
                aliveUpstream += 1
    return aliveUpstream + len(stack)
```

## 5. Problem 4: StoneWall

### Description
Count minimal blocks needed to build a wall with heights given by array H.

### Approach

Use stack of heights; push on height increase, pop on decrease.

### ✔ PHP Solution
```php
function solution($H) {
    $stack = [];
    $blocks = 0;

    foreach ($H as $h) {
        while (!empty($stack) && end($stack) > $h) {
            array_pop($stack);
        }
        if (empty($stack) || end($stack) < $h) {
            if ($h > 0) {
                array_push($stack, $h);
                $blocks++;
            }
        }
    }
    return $blocks;
}
```
### ✔ Python Solution
```python
def solution(H):
    stack = []
    blocks = 0
    for h in H:
        while stack and stack[-1] > h:
            stack.pop()
        if not stack or stack[-1] < h:
            if h > 0:
                stack.append(h)
                blocks += 1
    return blocks
```
