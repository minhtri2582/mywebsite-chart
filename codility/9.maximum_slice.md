# Maximum Slice Problem

Nhóm bài “Maximum slice” thường dùng 2 tư duy chính:

1) **Kadane (max subarray)** – tối ưu tổng lớn nhất của đoạn liên tiếp  
2) **Prefix best / DP 2 phía** – đặc biệt cho Double Slice

---

## 1) Problem: MaxProfit

### Description
Given array `A` where `A[i]` is a stock price on day `i`, find the maximum profit from **one transaction**:
- Buy on day `P`
- Sell on day `Q`
- `P <= Q`

If no profit possible, return `0`.

### Idea
Duyệt từ trái sang phải:
- Giữ `minPrice` (giá thấp nhất đã thấy)
- Profit tốt nhất tại ngày i là `A[i] - minPrice`
- Cập nhật `maxProfit`

### Complexity
- Time: **O(N)**
- Space: **O(1)**

### Example
A = [23171, 21011, 21123, 21366, 21013, 21367]  
→ maxProfit = 356 (buy 21011, sell 21367)

### ✔ PHP Solution
```php
function solution($A) {
    $n = count($A);
    if ($n < 2) return 0;

    $minPrice = $A[0];
    $maxProfit = 0;

    for ($i = 1; $i < $n; $i++) {
        $maxProfit = max($maxProfit, $A[$i] - $minPrice);
        $minPrice = min($minPrice, $A[$i]);
    }
    return $maxProfit;
}
````

### ✔ Python Solution

```python
def solution(A):
    n = len(A)
    if n < 2:
        return 0

    min_price = A[0]
    max_profit = 0

    for i in range(1, n):
        max_profit = max(max_profit, A[i] - min_price)
        min_price = min(min_price, A[i])

    return max_profit
```

## 2) Problem: MaxSliceSum

### Description

Find the maximum sum of any **non-empty** slice (contiguous subarray) of `A`.

### Idea (Kadane’s Algorithm)

Giữ:

* `maxEnding`: tổng lớn nhất của slice kết thúc tại i
* `maxSlice`: tổng lớn nhất toàn cục

Công thức:

* `maxEnding = max(A[i], maxEnding + A[i])`
* `maxSlice = max(maxSlice, maxEnding)`

### Complexity

* Time: **O(N)**
* Space: **O(1)**

### Example

A = [3, 2, -6, 4, 0]
Max slice = [4,0] → sum = 4

### ✔ PHP Solution

```php
function solution($A) {
    $n = count($A);
    $maxEnding = $A[0];
    $maxSlice  = $A[0];

    for ($i = 1; $i < $n; $i++) {
        $maxEnding = max($A[$i], $maxEnding + $A[$i]);
        $maxSlice  = max($maxSlice, $maxEnding);
    }
    return $maxSlice;
}
```

### ✔ Python Solution

```python
def solution(A):
    max_ending = A[0]
    max_slice = A[0]

    for x in A[1:]:
        max_ending = max(x, max_ending + x)
        max_slice = max(max_slice, max_ending)

    return max_slice
```

## 3) Problem: MaxDoubleSliceSum

### Description

A **double slice** is a triplet `(X, Y, Z)` such that:

* `0 <= X < Y < Z < N`

Sum is:

* `A[X+1] + A[X+2] + ... + A[Y-1]`
* plus
* `A[Y+1] + A[Y+2] + ... + A[Z-1]`

Notice: elements `A[X]`, `A[Y]`, `A[Z]` are excluded.
Goal: maximize this sum.

### Key Insight

Ta chọn một điểm “bỏ qua” Y (middle), rồi ghép:

* Best slice ending at `Y-1` (từ trái)
* Best slice starting at `Y+1` (từ phải)

Ta precompute 2 mảng:

* `left[i]`: max sum của slice kết thúc tại i (không âm), dạng Kadane nhưng clamp >=0
* `right[i]`: max sum của slice bắt đầu tại i (không âm)

Công thức:

* `left[i] = max(0, left[i-1] + A[i])` for i=1..N-2
* `right[i] = max(0, right[i+1] + A[i])` for i=N-2..1

Sau đó duyệt Y:

* best = max(best, left[Y-1] + right[Y+1])

### Complexity

* Time: **O(N)**
* Space: **O(N)** (2 arrays)

### Example

A = [3, 2, 6, -1, 4, 5, -1, 2]
Output = 17

### ✔ PHP Solution

```php
function solution($A) {
    $n = count($A);
    if ($n < 4) return 0;

    $left = array_fill(0, $n, 0);
    $right = array_fill(0, $n, 0);

    // left[i] = max sum ending at i (excluding negatives)
    for ($i = 1; $i < $n - 1; $i++) {
        $left[$i] = max(0, $left[$i - 1] + $A[$i]);
    }

    // right[i] = max sum starting at i (excluding negatives)
    for ($i = $n - 2; $i > 0; $i--) {
        $right[$i] = max(0, $right[$i + 1] + $A[$i]);
    }

    $best = 0;
    for ($y = 1; $y < $n - 1; $y++) {
        $best = max($best, $left[$y - 1] + $right[$y + 1]);
    }

    return $best;
}
```

### ✔ Python Solution

```python
def solution(A):
    n = len(A)
    if n < 4:
        return 0

    left = [0] * n
    right = [0] * n

    for i in range(1, n - 1):
        left[i] = max(0, left[i - 1] + A[i])

    for i in range(n - 2, 0, -1):
        right[i] = max(0, right[i + 1] + A[i])

    best = 0
    for y in range(1, n - 1):
        best = max(best, left[y - 1] + right[y + 1])

    return best
```

## Summary

| Problem           | Output               | Core Idea                    | Time | Space |
| ----------------- | -------------------- | ---------------------------- | ---- | ----- |
| MaxProfit         | max profit (>=0)     | track min price + best diff  | O(N) | O(1)  |
| MaxSliceSum       | max subarray sum     | Kadane                       | O(N) | O(1)  |
| MaxDoubleSliceSum | max double slice sum | Kadane 2 sides + skip middle | O(N) | O(N)  |
