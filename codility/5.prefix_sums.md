## Codility Lesson 5: Prefix Sums — Song ngữ Anh – Việt

### 1. PassingCars — Xe vượt nhau

✨ Problem / Bài toán

EN: Given an array A of 0s and 1s where 0 = car going east, 1 = car going west, count the number of pairs (P, Q) such that P < Q and A[P] = 0, A[Q] = 1.

VI: Cho mảng A gồm 0 và 1, trong đó 0 là xe đi đông, 1 là xe đi tây. Đếm số cặp (P, Q) sao cho P < Q, A[P]=0, A[Q]=1.

⸻

🔍 Key idea / Ý chính

	•	Duyệt qua từng phần tử, đếm số xe đi đông đã thấy (east_count).
	
	•	Mỗi khi gặp xe đi tây (1), cộng thêm east_count vào tổng.
	
	•	Nếu tổng vượt 1,000,000,000 → trả về -1.

⸻

📊 Example / Ví dụ

A	Result	Giải thích
[0,1,0,1,1]	5	Các cặp hợp lệ: (0,1),(0,3),(0,4),(2,3),(2,4)


⸻

💻 Python Code

```python
def passing_cars(A):
    east = 0
    pairs = 0
    for car in A:
        if car == 0:
            east += 1
        else:
            pairs += east
            if pairs > 1_000_000_000:
                return -1
    return pairs

print(passing_cars([0,1,0,1,1]))  # 5
```

💻 PHP Code

```php
<?php
function passing_cars(array $A): int {
    $east = 0; $pairs = 0;
    foreach ($A as $car) {
        if ($car === 0) {
            $east++;
        } else {
            $pairs += $east;
            if ($pairs > 1000000000) return -1;
        }
    }
    return $pairs;
}

echo passing_cars([0,1,0,1,1]); // 5
```

Complexity: O(N) time, O(1) space.

### 2. GenomicRangeQuery — Truy vấn chuỗi gen

✨ Problem / Bài toán

EN: Given a DNA sequence S consisting of A, C, G, T and arrays P, Q, find the minimal impact factor for each query range.

Impact factors: A=1, C=2, G=3, T=4.

VI: Cho chuỗi DNA S (gồm A, C, G, T) và mảng P, Q mô tả các đoạn truy vấn, tìm giá trị tác động nhỏ nhất trong mỗi đoạn.

⸻

🔍 Key idea / Ý chính

	•	Tạo prefix sum cho từng ký tự (A,C,G,T).
	
	•	Với mỗi truy vấn [P[i], Q[i]], kiểm tra xem có xuất hiện A, C, G, hay T trong đoạn đó qua prefix.

⸻

📊 Example / Ví dụ

S	P	Q	Result	Giải thích
CAGCCTA	[2,5,0]	[4,5,6]	[2,4,1]	Tác động nhỏ nhất cho mỗi đoạn


⸻

💻 Python Code

```python
def genomic_range_query(S, P, Q):
    n = len(S)
    pref = {'A':[0]*(n+1), 'C':[0]*(n+1), 'G':[0]*(n+1)}

    for i in range(1, n+1):
        for c in 'ACG':
            pref[c][i] = pref[c][i-1]
        if S[i-1] in 'ACG':
            pref[S[i-1]][i] += 1

    res = []
    for p,q in zip(P,Q):
        if pref['A'][q+1]-pref['A'][p]>0: res.append(1)
        elif pref['C'][q+1]-pref['C'][p]>0: res.append(2)
        elif pref['G'][q+1]-pref['G'][p]>0: res.append(3)
        else: res.append(4)
    return res

print(genomic_range_query('CAGCCTA',[2,5,0],[4,5,6]))  # [2,4,1]
```

💻 PHP Code

```php
<?php
function genomic_range_query(string $S, array $P, array $Q): array {
    $N = strlen($S);
    $pref = [
        'A' => array_fill(0, $N+1, 0),
        'C' => array_fill(0, $N+1, 0),
        'G' => array_fill(0, $N+1, 0)
    ];

    for ($i = 1; $i <= $N; $i++) {
        foreach (['A','C','G'] as $c) {
            $pref[$c][$i] = $pref[$c][$i-1];
        }
        $ch = $S[$i-1];
        if (isset($pref[$ch])) $pref[$ch][$i]++;
    }

    $result = [];
    foreach ($P as $idx => $p) {
        $q = $Q[$idx];
        if ($pref['A'][$q+1]-$pref['A'][$p] > 0) $result[] = 1;
        elseif ($pref['C'][$q+1]-$pref['C'][$p] > 0) $result[] = 2;
        elseif ($pref['G'][$q+1]-$pref['G'][$p] > 0) $result[] = 3;
        else $result[] = 4;
    }
    return $result;
}

print_r(genomic_range_query('CAGCCTA',[2,5,0],[4,5,6])); // [2,4,1]
```

Complexity: O(N+M) time, O(N) space.

### 3. MinAvgTwoSlice — Trung bình nhỏ nhất

✨ Problem / Bài toán

EN: Find the starting position of a slice with the minimal average value.

VI: Tìm vị trí bắt đầu của đoạn con có giá trị trung bình nhỏ nhất trong mảng.

⸻

🔍 Key idea / Ý chính

	•	Chỉ cần xét các đoạn dài 2 hoặc 3 là đủ, vì đoạn dài hơn luôn chứa một đoạn con nhỏ hơn có trung bình không lớn hơn.
	
	•	Tính trung bình cho từng cặp/triple liên tiếp, chọn vị trí có min.

⸻

📊 Example / Ví dụ

A	Result	Giải thích
[4,2,2,5,1,5,8]	1	Đoạn [2,2] có TB=2 nhỏ nhất


⸻

💻 Python Code

```python
def min_avg_two_slice(A):
    min_avg = float('inf')
    min_idx = 0
    for i in range(len(A)-1):
        avg2 = (A[i]+A[i+1])/2
        if avg2 < min_avg:
            min_avg = avg2
            min_idx = i
        if i < len(A)-2:
            avg3 = (A[i]+A[i+1]+A[i+2])/3
            if avg3 < min_avg:
                min_avg = avg3
                min_idx = i
    return min_idx

print(min_avg_two_slice([4,2,2,5,1,5,8]))  # 1
```

💻 PHP Code

```php
<?php
function min_avg_two_slice(array $A): int {
    $minAvg = INF; $minIdx = 0;
    for ($i=0; $i<count($A)-1; $i++) {
        $avg2 = ($A[$i]+$A[$i+1])/2;
        if ($avg2 < $minAvg) { $minAvg = $avg2; $minIdx = $i; }
        if ($i < count($A)-2) {
            $avg3 = ($A[$i]+$A[$i+1]+$A[$i+2])/3;
            if ($avg3 < $minAvg) { $minAvg = $avg3; $minIdx = $i; }
        }
    }
    return $minIdx;
}

echo min_avg_two_slice([4,2,2,5,1,5,8]); // 1
```

Complexity: O(N) time, O(1) space.
