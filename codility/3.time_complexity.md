## 1. FrogJmp — Nhảy ếch

### ✨ Problem / Bài toán

**EN:** Count the minimal number of jumps from position `X` to at least `Y`, given a fixed jump distance `D`.

**VI:** Tính số lần nhảy ít nhất để con ếch đi từ vị trí `X` đến vị trí `Y` (hoặc xa hơn), với mỗi lần nhảy có khoảng cách cố định `D`.

---

### 🔍 Key idea / Ý chính

* Mỗi bước nhảy tăng thêm `D`.
* Số bước tối thiểu là **phần làm tròn lên** của `(Y - X) / D`.
* Dùng `math.ceil()` hoặc công thức tương đương.

---

### 📊 Examples / Ví dụ

| X  | Y  | D  | Result | Giải thích         |
| -- | -- | -- | ------ | ------------------ |
| 10 | 85 | 30 | 3      | 10 → 40 → 70 → 100 |
| 10 | 10 | 5  | 0      | Đã ở vị trí đích   |

---

### 💻 Python Code

```python
import math

def frog_jmp(X, Y, D):
    if X >= Y:
        return 0
    return math.ceil((Y - X) / D)

print(frog_jmp(10, 85, 30))  # 3
```

### 💻 PHP Code

```php
<?php
function frog_jmp(int $X, int $Y, int $D): int {
    if ($X >= $Y) return 0;
    return (int)ceil(($Y - $X) / $D);
}

echo frog_jmp(10, 85, 30); // 3
```

**Complexity:** O(1) time, O(1) space.

## 2. PermMissingElem — Phần tử bị thiếu trong dãy hoán vị

### ✨ Problem / Bài toán

**EN:** Given an array `A` containing `N` distinct integers in the range `[1..N+1]`, find the missing element.

**VI:** Cho mảng `A` gồm `N` số nguyên phân biệt trong đoạn `[1..N+1]`. Hãy tìm phần tử bị thiếu.

---

### 🔍 Key idea / Ý chính

* Tổng lý thuyết của dãy từ `1..N+1` là:
  ( \text{sum} = (N+1)(N+2)/2 )
* Trừ đi tổng thực tế của `A`, ta được phần tử còn thiếu.

---

### 📊 Examples / Ví dụ

| A                     | Result | Giải thích          |
| --------------------- | ------ | ------------------- |
| [2, 3, 1, 5]          | 4      | Dãy 1..5 thiếu 4    |
| [1, 2, 3, 4, 5, 6, 8] | 7      | Thiếu 7             |
| []                    | 1      | Mảng rỗng → thiếu 1 |

---

### 💻 Python Code

```python
def perm_missing_elem(A):
    n = len(A)
    total = (n + 1) * (n + 2) // 2
    return total - sum(A)

print(perm_missing_elem([2,3,1,5]))  # 4
```

### 💻 PHP Code

```php
<?php
function perm_missing_elem(array $A): int {
    $n = count($A);
    $total = ($n + 1) * ($n + 2) / 2;
    return (int)($total - array_sum($A));
}

echo perm_missing_elem([2,3,1,5]); // 4
```

**Complexity:** O(N) time, O(1) space.

## 3. TapeEquilibrium — Cân bằng dải băng

### ✨ Problem / Bài toán

**EN:** Given a non-empty array `A` of `N` integers, split it into two non-empty parts and find the minimal absolute difference between their sums.

**VI:** Cho mảng `A` gồm `N` phần tử, chia thành 2 phần (mỗi phần không rỗng), tìm **hiệu tuyệt đối nhỏ nhất** giữa tổng hai phần.

---

### 🔍 Key idea / Ý chính

* Tính tổng toàn mảng `total`.
* Duyệt từ đầu → dần cộng `left_sum`, và tính `right_sum = total - left_sum`.
* Giữ `min_diff = min(min_diff, abs(left_sum - right_sum))`.

---

### 📊 Example / Ví dụ

| A              | Split (P) | Left      | Right   | Diff |
|----------------|-----------|------------|---------|------|
| [3, 1, 2, 4, 3] | P = 3     | [3, 1, 2] | [4, 3]  | 1    |

✅ Result = 1

---

### 💻 Python Code

```python
def tape_equilibrium(A):
    total = sum(A)
    left = 0
    min_diff = float('inf')

    for i in range(len(A) - 1):
        left += A[i]
        right = total - left
        diff = abs(left - right)
        min_diff = min(min_diff, diff)

    return min_diff

print(tape_equilibrium([3,1,2,4,3]))  # 1
```

### 💻 PHP Code

```php
<?php
function tape_equilibrium(array $A): int {
    $total = array_sum($A);
    $left = 0;
    $minDiff = PHP_INT_MAX;

    for ($i = 0; $i < count($A) - 1; $i++) {
        $left += $A[$i];
        $right = $total - $left;
        $diff = abs($left - $right);
        if ($diff < $minDiff) $minDiff = $diff;
    }

    return $minDiff;
}

echo tape_equilibrium([3,1,2,4,3]); // 1
```

**Complexity:** O(N) time, O(1) space.
