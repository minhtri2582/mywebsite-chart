# Codility Lesson 1: Iterations (Binary Gap) — Song ngữ Anh – Việt

## ✨ Problem / Bài toán

**EN:** Given a positive integer `N`, find the length of the longest sequence of consecutive zeros that is **surrounded by ones** in the binary representation of `N` (the “binary gap”).

**VI:** Cho số nguyên dương `N`, hãy tìm độ dài dãy số 0 liên tiếp **được kẹp giữa hai số 1** trong biểu diễn nhị phân của `N` (gọi là “binary gap”).

---

## 🔍 Key idea / Ý chính

* **Ignore trailing zeros** (they aren’t closed by a `1`).
* Start counting zeros **after** the first `1`; when another `1` appears, **close** the gap and update `max`.
* Bitwise scan is O(log N) and memory O(1).

---

## 📊 Examples / Ví dụ

| N (dec) | Binary       | Longest gap | Ghi chú (VI)                             |
| ------: | ------------ | ----------- | ---------------------------------------- |
|     529 | `1000010001` | 4           | Hai khoảng: 4 và 3 → lấy 4               |
|      20 | `10100`      | 1           | `10(1)00` → đuôi “00” không tính         |
|      15 | `1111`       | 0           | Không có số 0 giữa hai số 1              |
|       9 | `1001`       | 2           | Khoảng “00” dài 2                        |
|      32 | `100000`     | 0           | Toàn bộ “00000” là đuôi, không kẹp bởi 1 |

---

## 💻 Python Code (bitwise scan)

```python
def binary_gap(N: int) -> int:
    # Skip trailing zeros (rightmost), they can't form a closed gap
    while N > 0 and (N & 1) == 0:
        N >>= 1

    max_gap = 0
    cur = 0
    while N > 0:
        if (N & 1) == 0:
            cur += 1
        else:
            if cur > max_gap:
                max_gap = cur
            cur = 0
        N >>= 1
    return max_gap

# quick checks
for t in [529, 20, 15, 9, 32]:
    print(t, binary_gap(t))  # 529→4, 20→1, 15→0, 9→2, 32→0
```

## 💻 PHP Code (bitwise scan)

```php
<?php
function binary_gap(int $N): int {
    // Skip trailing zeros
    while ($N > 0 && ($N & 1) === 0) {
        $N >>= 1;
    }

    $maxGap = 0;
    $cur = 0;

    while ($N > 0) {
        if (($N & 1) === 0) {
            $cur++;
        } else {
            if ($cur > $maxGap) $maxGap = $cur;
            $cur = 0;
        }
        $N >>= 1;
    }
    return $maxGap;
}

// quick checks
$tests = [529, 20, 15, 9, 32];
foreach ($tests as $t) {
    echo $t . " => " . binary_gap($t) . PHP_EOL; // 529=>4, 20=>1, 15=>0, 9=>2, 32=>0
}
```

---

## 🧠 Common pitfalls / Lỗi thường gặp

* **Counting trailing zeros** at the end (not surrounded by `1`).
* Starting to count **before** the first `1`.
* Forgetting to reset the zero counter after each closing `1`.

---

## ⏱️ Complexity / Độ phức tạp

* **Time / Thời gian:** `O(log N)` (số bit của N).
* **Space / Bộ nhớ:** `O(1)`.
