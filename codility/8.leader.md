## 🥇 Lý thuyết Codility – Leader

📌 Định nghĩa

Một phần tử được gọi là Leader của mảng nếu:
-	Nó xuất hiện nhiều hơn N/2 lần trong mảng
-	(N = số phần tử trong mảng)

Ví dụ:

A = [3, 1, 3, 3, 2]

	•	Số lần xuất hiện:
	•	3 → 3 lần
	•	1 → 1 lần
	•	2 → 1 lần

Ở đây N = 5, nên N/2 = 2.5

Ai xuất hiện > 2.5 lần? → 3

👉 3 là Leader của mảng

Nếu không có phần tử nào xuất hiện > N/2 → mảng không có leader.

⸻

⚠ Nhận xét quan trọng

-	Mảng chỉ có nhiều nhất 1 leader
-	Nếu leader tồn tại → leader là majority element

⸻

## 🪄 Ý tưởng giải nhanh – Thuật toán Boyer–Moore Majority Vote

(Không cần sort, không cần hash map, chạy O(N) và O(1) space)

Ý tưởng
-	Nếu ta ghép 2 phần tử khác nhau lại → chúng tự triệt tiêu
-	Chỉ phần tử xuất hiện nhiều nhất sống sót cuối cùng

Mô phỏng

A = [3, 1, 3, 3, 2]

| Step | Value | Candidate | Count | Action              |
|------|--------|------------|--------|----------------------|
| 1    | 3      | 3          | 1      | chọn 3               |
| 2    | 1      | 3          | 0      | khử 3 với 1          |
| 3    | 3      | 3          | 1      | chọn lại 3           |
| 4    | 3      | 3          | 2      | tăng count           |
| 5    | 2      | 3          | 1      | giảm count (3 vs 2)  |

👉 Candidate cuối = 3
Sau đó kiểm tra lại xem xuất hiện > N/2 không → đúng → leader

⸻

## 🧠 Các dạng bài Codility liên quan Leader

### 1. Bài Dominator

Link trong codility: Arrays → Dominator

Yêu cầu:
-	Tìm index bất kỳ của leader trong mảng
-	Nếu không có leader → trả về -1

Ví dụ

A = [3, 4, 3, 2, 3, -1, 3, 3]

	•	3 xuất hiện 5 lần
	•	N = 8 → N/2 = 4
	•	3 > 4 → leader

👉 Trả về index của 3, ví dụ 0, 2, 4, 6, 7 đều đúng.

⸻

🎯 Code PHP Dominator (score 100% Codility)

```php
function solution($A) {
    $size = 0;
    $value = null;
    
    // Boyer–Moore: tìm candidate
    foreach ($A as $num) {
        if ($size == 0) {
            $value = $num;
            $size = 1;
        } else {
            $size += ($num == $value) ? 1 : -1;
        }
    }
    
    // Kiểm tra lại leader
    if ($size == 0) return -1;
    
    $count = 0;
    $index = -1;
    foreach ($A as $i => $num) {
        if ($num == $value) {
            $count++;
            $index = $i;
        }
    }

    return ($count > count($A) / 2) ? $index : -1;
}
```

⸻

### 2. Bài EquiLeader

Bài này yêu cầu:
-	Tìm số vị trí S chia mảng thành 2 phần
-	sao cho leader của phần bên trái = leader của phần bên phải

Ví dụ:

A = [4, 3, 4, 4, 4, 2]

Chia tại S = 2:

Left:  [4, 3, 4] → leader 4 (2 lần > 3/2)
Right: [4, 4, 2] → leader 4 (2 lần > 3/2)

=> S = 2 là equileader

Tổng equi leader = 2 (ở S = 2 và S = 3)

⸻

### 🎯 Code PHP EquiLeader (100% Codility)

```php
function solution($A) {
    // 1. Tìm leader candidate
    $size = 0;
    $value = null;

    foreach ($A as $num) {
        if ($size == 0) {
            $value = $num;
            $size = 1;
        } else {
            $size += ($num == $value) ? 1 : -1;
        }
    }

    // 2. Đếm số lần xuất hiện
    $count = 0;
    foreach ($A as $num) {
        if ($num == $value) $count++;
    }
    if ($count <= count($A)/2) return 0; // không có leader

    $leader = $value;
    $equi = 0;
    $leftCount = 0;

    // 3. Duyệt từng phần chia
    for ($i = 0; $i < count($A); $i++) {
        if ($A[$i] == $leader) $leftCount++;

        if ($leftCount > ($i + 1)/2 &&
           ($count - $leftCount) > (count($A) - $i - 1)/2) {
            $equi++;
        }
    }

    return $equi;
}
```

## 📚 Tổng kết lý thuyết Leader

| Khái niệm     | Ý nghĩa                                             |
|---------------|-----------------------------------------------------|
| Leader        | Phần tử xuất hiện > N/2 lần                         |
| Chỉ có 1 leader hoặc không có | Leader là duy nhất nếu tồn tại      |
| Boyer–Moore   | Thuật toán tìm candidate leader trong O(N) time     |
| Dominator     | Bài toán tìm index bất kỳ của leader                |
| EquiLeader    | Số điểm chia mảng sao cho 2 phần đều có cùng leader |
