🔸 General Cloud Services

⸻

🧑‍💼 Interviewer:
Can you explain the difference between object storage and file storage in cloud platforms?

🧑‍💻 Candidate (You):
Yes.
•	Object Storage (e.g., AWS S3, Azure Blob Storage):
Stores data as objects with metadata. Ideal for unstructured data like images, videos, backups. Accessed via HTTP APIs.
•	File Storage (e.g., Azure File Storage, Amazon EFS):
Provides shared, mountable file systems for traditional applications. Best for lift-and-shift workloads or legacy systems expecting a POSIX-compliant filesystem.

🟦 AWS Services

⸻

🧑‍💼 Interviewer:
What are the key features of Amazon S3?

🧑‍💻 Candidate:
Amazon S3 (Simple Storage Service) is an object storage service with:
•	Unlimited storage, highly durable (99.999999999%)
•	Versioning and lifecycle policies
•	Server-side encryption (SSE-S3, SSE-KMS)
•	Pre-signed URLs for temporary access
•	Bucket policies and IAM roles for access control
•	Supports hosting static websites and integrates with services like CloudFront and Lambda

⸻

🧑‍💼 Interviewer:
What is AWS Lambda and when would you use it?

🧑‍💻 Candidate:
AWS Lambda is a serverless compute service where you run code without managing servers. Key features:
•	Automatically scales
•	Billed per invocation and execution time
•	Event-driven (e.g., trigger from S3, API Gateway, CloudWatch)

Use cases include:
•	File processing (e.g., image resize on S3 upload)
•	Lightweight APIs
•	Automation and scheduled tasks

🧑‍💼 Interviewer:
How is ECS different from EKS in AWS?

🧑‍💻 Candidate:
•	ECS (Elastic Container Service):
AWS’s native container orchestration. Easier to set up, supports Fargate (serverless containers). Less flexibility than Kubernetes but fully managed by AWS.
•	EKS (Elastic Kubernetes Service):
Fully managed Kubernetes service. Offers portability, open-source tooling, and flexibility. Ideal for teams already using Kubernetes or multi-cloud environments.

Use ECS for simplicity, EKS for standardization and flexibility.

⸻

🧑‍💼 Interviewer:
What is AWS RDS and what types of databases does it support?

🧑‍💻 Candidate:
Amazon RDS (Relational Database Service) is a managed service for relational databases. AWS handles provisioning, patching, backups, and failover.

It supports:
•	MySQL
•	PostgreSQL
•	MariaDB
•	Oracle
•	SQL Server
•	Amazon Aurora (MySQL/PostgreSQL compatible, optimized for AWS)

RDS offers Multi-AZ for HA and Read Replicas for scalability.

🟦 Azure Services

⸻

🧑‍💼 Interviewer:
What is Azure Blob Storage and how does it differ from Azure File Storage?

🧑‍💻 Candidate:
•	Azure Blob Storage:
Object storage for unstructured data (media files, backups, logs). Ideal for cloud-native apps, supports REST API and SDKs.
•	Azure File Storage:
Managed file shares accessible via SMB or NFS protocols. Useful for lift-and-shift apps and hybrid cloud scenarios.

Blob is for scalable, internet-accessible object data. File Storage is for mountable, shared file systems.

⸻

🧑‍💼 Interviewer:
What is Azure Function, and how does it compare to AWS Lambda?

🧑‍💻 Candidate:
Azure Function is Microsoft’s serverless compute offering. Similar to AWS Lambda:
•	Event-driven
•	Supports multiple triggers (HTTP, timer, storage, queues)
•	Offers Consumption Plan (pay-per-use) and Premium Plan (for VNET support and pre-warmed instances)

The core difference is integration: Azure Functions natively integrates better with Azure ecosystem (like Event Grid, Logic Apps), while Lambda integrates tightly with AWS services.

🧑‍💼 Interviewer:
What is AKS, and how does it differ from EKS?

🧑‍💻 Candidate:
AKS (Azure Kubernetes Service) and EKS (AWS) are both managed Kubernetes services. Key differences:

Feature	AKS	EKS
Ease of Setup	Simpler initial setup	Slightly more involved
Default Features	Free control plane, auto-scaling	Paid control plane
Node Pools	VMSS + Spot instances	EC2 or Fargate
Identity Integration	Azure AD	IAM, OIDC
Networking	Azure CNI or Kubenet	VPC CNI Plugin

Both support Helm, Ingress, and GitOps tools. Choose based on cloud provider and ecosystem alignment.

🧑‍💼 Interviewer:
What database services are available in Azure, similar to AWS RDS?

🧑‍💻 Candidate:
Azure offers Azure Database for… managed services:
•	Azure SQL Database (equivalent to SQL Server in RDS)
•	Azure Database for PostgreSQL
•	Azure Database for MySQL
•	Azure Cosmos DB for NoSQL
•	Azure Managed Instance for near full SQL Server compatibility

These services support high availability, backups, and scaling — similar to AWS RDS.

🧑‍💼 Interviewer:
How do you use KMS in AWS and Key Vault in Azure?

🧑‍💻 Candidate:
•	AWS KMS: Manages encryption keys. Integrated with S3, EBS, RDS, Lambda, Secrets Manager. Supports automatic key rotation and IAM-based access.
•	Azure Key Vault: Manages secrets, certificates, and keys. Integrated with Azure services. Supports RBAC, Managed Identity for access, and key rotation policies.

Both support hardware security modules (HSM) and logging via CloudTrail (AWS) or Monitor Logs (Azure).
